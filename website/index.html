cache-aware routingpython · node.js · zero deps

The cache decides the cost. So route for the cache.

Most routers ask which model is smartest. Prompt caches are model-scoped and non-transferable, so a router that switches models mid-conversation can cost more than not routing at all. llmrouter scores the (model, backend) pair, holds the session sticky, and picks a TTL for every prompt segment. This one keeps the cache warm.

Three questions, not one

The cost of a request is not decided by the model alone. Workload class and deployment class compose instead of being decided sequentially — every candidate is scored as a (model, backend) pair.

01

Which model?

workload class, quality floor, budget

Scored against a measured quality floor with hard constraints and closed-loop budget pacing.

02

Which backend?

self-hosted vs API vs serverless, live health, residency

Per-pair scoring with a circuit breaker that recovers through one canary request, and rendezvous hashing that survives membership changes.

03

Which cache TTL?

expected idle gap, generation time, prompt segment

Mixed TTL per breakpoint: stable system and tool segments hold the 1-hour tier, conversation history the 5-minute one.

Four stages,
under ten milliseconds.

The decision layer never touches the network and never blocks on a model. Drive your own client from decide(), or let Python's acomplete() execute for you.

    Twelve ideas, each pinned by a test
    
    
    A selection of what this router does that the category does not. Every claim has a matching assertion in both the Python and Node suites.
    

    
    
      
    
        delegation.py
        
    Delegate instead of switching
    
        
    Mid-session model switching destroys the cache. Delegation does not: a frontier lead and a cheaper sidekick run with two separate contexts and two separate warm caches, exchanging only a brief. Routing is by task phase — observable from the tool-call history — not by difficulty, which is not. Planning is lead-only: exploration that shapes the plan stays with the lead.

    policy.py
    Pairs, not models
    Quality, cost, latency, switch cost and measured affinity are scored per (model, backend) pair, so the workload axis and the deployment axis compose instead of being decided sequentially.
    
      
    economics.py
    TTL per breakpoint
    Stable prefixes hold the 1-hour tier; append-only history holds the 5-minute one, because paying 2× to re-cache it is waste. The decision uses expected_gap + generation_time.
    
      
    economics.py
    Stickiness with an amortization test
    A one-way migration must pay back its cold write inside the turns left (R*). If it cannot, the session stays put and a stranded counter increments where you can see it. A session that already migrated never migrates again.
    
      
    types.py
    Rule F: cold on drift
    Tool schemas, image usage and thinking settings sit inside the provider's cache key. If they drift mid-session, every candidate scores cold for that turn and the decision says so.
    
      
    policy.py
    Hard constraints, honest failure
    Pre-call context-window validation. Residency fails closed. Budget caps pick the cheapest violator and report it. Decision p50 under 10 ms, enforced by the CI gate.
    
      
    learning.py
    Quality you can train
    llmrouter train fits one logistic head per model from your feedback JSONL and ships a frozen 17-weight checkpoint. Blend: prior + λ·(b + w·x), λ = n/(n+k) — no data, old behavior.
    
      
    router.py
    Streaming that respects the first token
    astream() fails over while nothing has reached the caller and finishes with real usage counters. After the first token it raises rather than duplicating text you already rendered.
    
      
    store.py
    State that outlives the process
    Session pins, hit-rate EWMAs, circuit health and pair economics fit one atomic JSON snapshot with every timestamp rebased on restore. Python and Node read the same file.
    
      
    serve.py
    A gateway surface, not a rewrite
    Running LiteLLM, Bifrost or your own proxy? llmrouter serve answers POST /decide with the full decision in one wire format, and learns from the provider counters you report back.
    
      
    local.py
    The laptop is a backend
    Router.with_ollama() prices GPUs in honest dollars: $/MTok = rent / (tps × 3600) × 10⁼. An 8-second timeout and capacity shedding beat the cascade trap; saturated local traffic fails over to the API and drains back.
    
      
    classifiers.py
    Turn-1 inference you can afford
    When rules and fingerprints abstain, a small “System 1” model answers once: adapters for Laya, Codiv-hosted Verdict, GLiClass, or any callable, chained in your order. Failure is always a clean abstention.
    
    
    
  
    

    



    
  
    
    
    Routing policy is data
    
    
    Six decisions most routers make by instinct. Here each one is a named, testable rule with the arithmetic it runs on — not a vibe.
    
    
    
      
    
        
    01
    
        
    Cache-first stickiness
    
        
    Stay on a pair until a migration pays back inside the remaining turns.
    
        R* = (c'w' − cr) / ((c − c')r)
        4.75 turns sonnet→haiku
      
    
      
    
        
    02
    
        
    Mixed TTL policy
    
        
    System and tools hold the long tier; append-only history holds the short one.
    
        gap + generation_time > 300s
        1h / 5m per breakpoint
      
    
      
    
        
    03
    
        
    Canary recovery
    
        
    A tripped circuit recovers through a single live probe, never by polling.
    
        closed → open → half-open
        1 probe to close
      
    
      
    
        
    04
    
        
    Budget pacing
    
        
    Projected session spend against the remaining budget, priced into every score.
    
        argmin cost  s.t.  quality ≥ floor
        fails loud not degraded
      
    
      
    
        
    05
    
        
    Residency, fail closed
    
        
    No compliant candidate means the request is refused, not quietly degraded.
    
        region ∈ allowed set
        0 leaks or it doesn't run
      
    
      
    
        
    06
    
        
    Rendezvous affinity
    
        
    Stable hashing keeps a session on the same pair across replicas and membership changes.
    
        argmax hash(key · backend)
        HRW not a hash ring
      
    
    
    
  
    

    



    
  
    
    
    The learning layer, on the command line
    
    
    Five commands that form the loop — inspect, gate, tune, learn, serve — all on the pure decision layer, no keys, no network. Identical in both runtimes.
    
    
    
      
    
        
    01
    explain
    inspect
    
        
    Route one prompt and print the full auditable decision: candidates, scores, TTL choices, and why the workload class was picked.
    
        
    $llmrouter explain --prompt "hi" --workload chat
    
        
    → gpt-frontier-class@openai · q 0.92 · $0.011/turn · ttl system=5m
    
      
    
      
    
        
    02
    eval --ci
    gate
    
        
    Run a JSONL case file and gate it: exit 1 when quality drops below the floor, cases become unroutable, expected models disagree, or decision p50 passes 10 ms. The pre-merge gate.
    
        
    $llmrouter eval --data cases.jsonl --ci --quality-floor 0.75
    
        
    → avg quality 0.86 · p50 0.4ms · 200 routed · gate passed
    
      
    
      
    
        
    03
    calibrate
    tune
    
        
    Sweep the quality floor and report the value that hits your target strong-model share. The RouteLLM calibration pattern, generalized past two models.
    
        
    $llmrouter calibrate --data cases.jsonl --target-strong-pct 0.5
    
        
    → min_quality = 0.70 → 52% strong-model share on 200 cases
    
      
    
      
    
        
    04
    train
    learn
    
        
    Fit logistic quality heads from feedback JSONL (pointwise or pairwise) and write a frozen checkpoint both engines load identically.
    
        
    $llmrouter train --data feedback.jsonl --out quality.json
    
        
    → wrote 2 quality head(s) → quality.json · eval acc 1.00
    
      
    
      
    
        
    05
    serve
    expose
    
        
    The decision as an HTTP sidecar for LiteLLM, Bifrost or your own proxy; same wire format in both runtimes.
    
        
    $python -m llmrouter serve --port 8787
    
        
    → decide-sidecar on http://127.0.0.1:8787 · POST /decide

    Honest expectations
    
      
    Budget 30–40% cost reduction at ≤2% quality loss. Numbers like 85% come from easy benchmarks and input-only cost accounting. The arithmetic that actually decides: if your strong/weak price gap is under about 3×, routing cannot pay for itself. Ship the eval --ci gate and measure your own traffic.
